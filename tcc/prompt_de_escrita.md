# Prompt de Escrita para TCC

## Regras de Formatação

### Formatação de Parágrafos
- Cada parágrafo deve ser escrito em **uma única linha**
- Não quebre linhas dentro de um parágrafo
- Isso facilita o versionamento e comparação de mudanças (git diff)

### Formatação Markdown
- **Não use formatação excessiva em markdown**
- Evite marcadores como `##` para títulos de seção (use texto simples)
- **Não inclua marcadores de página** (ex: ## 2, ## 3)
- Mantenha formatação mínima e limpa

### Exemplo de Formatação Correta

```markdown
Nos últimos anos, a democratização do acesso à leitura tem se consolidado como um desafio social relevante, especialmente em um país onde milhões de pessoas ainda enfrentam barreiras para ter contato com livros e materiais literários. Em um cenário onde a educação e a cultura são fundamentais para o desenvolvimento humano, o Sistema Cangaceiro das Letras foi desenvolvido como uma solução tecnológica para facilitar a doação de livros, conectando diretamente doadores a instituições sociais que promovem a leitura em suas comunidades.
```

### Exemplo de Formatação Incorreta

```markdown
Nos últimos anos, a democratização do acesso à leitura tem se consolidado como um desafio social
relevante, especialmente em um país onde milhões de pessoas ainda enfrentam barreiras para ter
contato com livros e materiais literários. Em um cenário onde a educação e a cultura são
fundamentais para o desenvolvimento humano, o Sistema Cangaceiro das Letras foi desenvolvido como uma
solução tecnológica para facilitar a doação de livros, conectando diretamente doadores a
instituições sociais que promovem a leitura em suas comunidades.
```

## Estrutura do Documento

### Cabeçalho
- Título do trabalho
- Nomes dos autores com numeração
- Instituição
- Emails dos autores

### Resumo e Abstract
- Cada um deve ser escrito em uma única linha
- Resumo em português
- Abstract em inglês

### Seções
- Numeração simples (1. Introdução, 2. Metodologia, etc.)
- Sem marcadores de página

### Parágrafos
- Cada parágrafo em uma única linha, sem quebras
- Separar parágrafos com linha em branco
- Facilita identificação de mudanças no controle de versão

### Referências
- As referências devem aparecer na ordem em que são citadas no texto
- Primeira citação no texto = primeira referência na lista
- Manter ordem cronológica de aparição

## Tom e Estilo de Escrita

### Linguagem Acadêmica e Objetiva
- Use tom **objetivo e sóbrio**, apropriado para trabalho acadêmico
- Evite **linguagem promocional ou laudatória** sobre o sistema
- Não use frases de efeito ou superlativos desnecessários
- Este é um **trabalho de conclusão, não um pitch de produto**

### Exemplos de Linguagem Inadequada
❌ "O sistema proporciona uma experiência transparente e prática"
❌ "A solução inovadora revoluciona o processo de doação"
❌ "Interface moderna e intuitiva que encanta o usuário"

### Exemplos de Linguagem Adequada
✅ "O sistema tem como objetivo facilitar o processo de doação"
✅ "O sistema foi desenvolvido para conectar doadores e instituições"
✅ "A interface permite que usuários realizem cadastros e consultas"

### Diretrizes
- Descreva **funcionalidades** em vez de qualidades subjetivas
- Use verbos como "permite", "possibilita", "tem como objetivo"
- Foque em **o que o sistema faz**, não em quão bem ele faz
- Quando necessário destacar objetivos, use "busca", "visa", "pretende"

## Instruções para IA

Ao escrever ou editar o TCC:

1. **Cada parágrafo deve ser uma única linha**, sem quebras
2. **Separe parágrafos com linha em branco**
3. **Não use formatação excessiva em markdown** - mantenha simples
4. **Não inclua marcadores de página** (ex: ## 2, ## 3)
5. **Mantenha a consistência** em todo o documento
6. **Preserve a formatação** ao fazer edições
7. **Use linguagem acadêmica objetiva**, evitando linguagem promocional
8. **Descreva funcionalidades**, não qualidades subjetivas
9. **Base-se no tcc_yessir.md** para estrutura, mas adapte o conteúdo
10. **Consulte descricao_sistema_web_cangaceiro_das_letras.md** para informações factuais
11. **Evite cópias diretas** - reescreva com suas próprias palavras
12. **Varie a ordem dos temas** em relação ao TCC de referência

## Benefícios

- Facilita revisões e comparações (git diff)
- Cada mudança de parágrafo aparece claramente no histórico
- Padrão profissional de documentação
- Mais fácil de identificar mudanças em sistemas de controle de versão
